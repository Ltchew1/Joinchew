    What This Actually Is

    A real registry, traced live — consent always simulated.

    Every capability, gate, provider status, and jurisdiction shown above comes from a live query against CHEW's actual capability registry — the same read-only, public endpoint (/api/capability-routing) that powers the homepage's Opportunity Radar. Only the need itself is a sample: nine illustrative starting points, clearly marked, standing in for what a real visitor might tell CHEW. As of today the registry has zero active providers seeded for any capability, so honestly, every route here currently ends at NO VERIFIED LIVE ROUTE YET — that's not a bug in the demo, it's CHEW refusing to fabricate a referral that doesn't exist. The "Grant simulated consent" step, when a route is available, never actually shares anything or writes anything — nothing in this page calls CHEW's real consent-recording or routing-event systems. This is a demonstration of how the machinery works, not a live handoff.
